# Web Docs

Read these in this order:

1. `docs/DEVELOPER_CONTEXT.md`
2. `docs/questions.md`
3. `README.md`

This folder exists to make handoff easier for:

- frontend developers
- backend developers touching the web layer
- AI/code assistants that need fast repo context

Current scope of this repo:

- browser-facing CRM web app
- SuperTokens-based auth/session layer
- future backend-for-frontend (BFF) layer for the Go CRM service

Out of scope for this repo:

- core CRM data model and domain API logic
- import-profile backend logic
- database migrations for the CRM service

Those live in the separate repo:

- `lisent.ai-CRM-service`
